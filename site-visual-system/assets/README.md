# glass-kit

暗底毛玻璃 UI + 高斯模糊入场动效套件。从一个 Next.js 生产站点约 6000 行的
`globals.css` 里抽取，数值与线上一致，含完整的移动端 / 低端安卓降级与无障碍处理。

**零第三方运行时依赖**：CSS 纯原生，React 组件只用到 `useRef` / `useEffect` /
原生 `IntersectionObserver` / `ResizeObserver`。

## 先看效果

直接用浏览器打开 `demo.html`（不需要构建、不需要起服务器、不联网）。
里面演示了：卡片入场雾中浮现、hover 聚焦景深、3D 跟手倾斜与封面视差、
斜向流光扫过、主体越框弹出、玻璃面板 / 侧光条菜单 / 下拉 / 扫掠细线样板、
导航栏下滑隐藏、八色霓虹文字、颜文字 LED 点阵、影院海报墙与霓虹跑马灯。

打开后建议做七件事验证：
1. 鼠标在卡片上移动 —— 卡片该跟手倾斜，封面图以更慢的速度反向错动（图与卡分离感）。
2. 滚动到底再滚回顶 —— 卡片入场动画该**重播**，而不是只播一次。
3. 鼠标在顶部选项条上来回移动 —— 凹陷高亮块该带过冲弹性滑移、宽度同步变化；
   **点击**切换选项时，选中发光胶囊该从旧选项**滑**到新选项，而不是瞬移。
4. 点右下角悬浮按钮 —— 弹窗该从按钮位飞行放大弹入，果冻皮中途溶解，内容最后点亮、
   毛玻璃同步淡入（弹窗后面的背景明显变糊）；收回时一气呵成、收尾没有停顿。
5. 往下滚动页面 —— 顶部导航栏该向上收走；往回滚立刻出现。
6. 看霓虹文字与 LED 点阵区 —— 每条霓虹字偶尔**各自**微抖一下（错峰，不齐抖）；
   每条颜文字点阵整条轻轻浮动、稀疏「坏灯珠」忽明忽暗。
7. 影院海报墙区 —— 整体斜向、相邻列一来一回反方向滚动；悬停某列**整列停滚**，
   悬停某张海报它发光、其余全部降亮（聚光灯）；上下霓虹条反方向滚、闪烁**错峰**。
8. 系统开启「减少动态效果」后刷新 —— 位移/缩放/流光/抖动/滚动该全停，但颜色与发光仍在。

## 五步接入

1. **引入 CSS**：`import "./glass-kit.css"`。
   Tailwind 项目要放在 `@tailwind utilities` **之后**，否则 `.glass-card` 的圆角会被基类盖掉。

2. **铺背景层 —— 这步不能省**：
   ```html
   <div class="bg-texture"></div>
   <div class="grid-texture"></div>
   ```
   两者是 `position: fixed; z-index: -1`，是**所有 `backdrop-filter` 的采样源**。
   没有它玻璃就没东西可糊、退化成均匀半透明色块 ——「玻璃看起来是假的」十有八九是漏了这步。
   想用图片背景就换成一张 `position: fixed; z-index: -1; object-fit: cover` 的图。

3. **搭卡片三层结构**（层级不可合并，原因见下方铁律 2）：
   ```tsx
   <EnterOnView cheapReplay={isAndroid} hasOverflowPop={!!maskUrl}>
     <CardTilt>
       <div className="glass-card">
         <div className="card-media"><img src={cover} alt="" /></div>
         <div className="frosted-glass">{/* 标题 / 元信息 */}</div>
       </div>
       {/* 可选：主体越框弹出层，必须是 .glass-card 的兄弟 */}
       <div className="card-pop" style={{ aspectRatio: "3 / 4" }}>
         <img src={cover} alt=""
              style={{ maskImage: `url(${maskUrl})`, maskMode: "luminance" }} />
       </div>
     </CardTilt>
   </EnterOnView>
   ```
   `EnterOnView` 自己会渲染 `.card-shell` 外壳，不要再手动包一层。
   卡片外层网格容器加 `.card-grid`（邻卡后退的景深效果靠 `.card-grid:hover` 生效）。

4. **换主题色**：改 `:root` 的 `--accent-color` / `--accent-glow` 两行即可。
   流光、侧光条、扫掠细线里还有三处硬编码的柠檬绿，要彻底换色一起搜
   `163, 230, 53` 和 `190, 242, 100`。

5. **验收**：跑下面的检查清单。

## 六个「招牌」效果

这几个是最容易做歪的，参数都从原站抄来，改之前先理解为什么。

### 滑动高亮（`.jelly-nav` + `JellyNav.tsx`）

凹陷高亮块跟着 hover 的选项弹性滑移，宽度同步变化；选中项另有一个发光胶囊，
点击切换时从旧选项**滑**到新选项（伪元素 `::before` 只能这边灭那边亮地瞬移，
所以选中态必须是独立滑动块）。

- **凹陷感靠「暗底 + 短投影 + 顶部内高光」三件套**，不是发光而是压下去。做成发光就变味了。
- 位置量的是「按钮左边缘**相对容器**左边缘」的距离，不是视口绝对量 —— 页面滚动时无需重算。
- 移出整条时只淡出、**不归零位置**。下次进入是从上次停留处滑过去，而不是跳回最左再滑出来。
- 弹性来自过冲贝塞尔 `cubic-bezier(0.34, 1.4, 0.64, 1)` / 0.34s。
  原站用的是 framer-motion spring `{ stiffness: 420, damping: 28, mass: 0.55 }`
  （opacity 单独 0.14s 快速淡入，让高亮显得「活」而不是慢慢显形）。想要完全一致就换回 spring。
- 凹陷块不挂触屏监听：没有 hover 的设备上这块高亮没有意义，且手指滑动会误触发。
  选中发光胶囊不受此限 —— 选中是状态不是指针反馈，触屏也要跟着点击走。

### 果冻形变（`.jelly-morph-*` + `JellyMorph.tsx`）

悬浮按钮点击后「长成」居中弹窗，关闭反向收回。

- **不用真 FLIP**（framer-motion `layout` / View Transitions）。真 FLIP 每帧都在重绘剧烈变
  尺寸的图层（borderRadius 校正 + boxShadow 插值），低端安卓 WebView 实测闪屏、纹理重分配
  跟不上。这里走「假形变」：面板一次光栅化后整体做 `transform` + `opacity`，全程合成线程、
  零每帧重绘，桌面观感几乎无差别，也不引依赖。
- **三个时机必须解耦，别合并**：
  | 时机 | 做什么 | 为什么 |
  | --- | --- | --- |
  | 双 rAF 后 | 才加 `.is-flying` 起跑 | 面板先以缩小态挂载 2 帧完成光栅化，消起手卡顿 |
  | 240ms | 果冻皮溶解 | 弹窗刚冲到最大、还在回弹的动态中就化开，强调色不等站定，过渡更紧凑 |
  | 480ms | 内容点亮 + 毛玻璃淡入 | `scale` 贴近 1 才显示。缩放途中绘制 `backdrop-filter` 会逐帧重采样卡顿（最初病根）；毛玻璃由独立内层 `.jelly-morph-glass` 以 opacity 淡入（本身不能过渡），面板底色同步转半透明 |
- **打开瞬间按钮瞬撤而非淡出**（`display: none`）：否则角落那团强调色与飞向中心的果冻皮会
  形成「两团绿」连闪。关闭方向按钮正常淡入。
- 关闭时**先隐藏内容再收面板**：果冻皮回绿过程中是半透明的，内容若仍可见会随缩放扭曲透出。
- **滚动解锁推迟到回缩完成**：立即解锁会触发整页 reflow 吃掉退出动画。
- 飞行向量 = 视口中心 → 按钮中心，打开瞬间采样。常量 `FAB_CENTER_OFFSET = 52`
  （`1.5rem` 边距 + `1.75rem` 半径），改 `.jelly-fab` 尺寸/位置要同步改，否则起点对不上按钮。
- 弹簧参数：开 `{ 290, 21, 1 }`（低阻尼过冲），关 `{ 380, 28, 0.9 }`（高阻尼干脆）。
  套件用等效贝塞尔 0.52s / 0.38s 近似。

### 霓虹文字（`.neon-*`）

八色强发光文字 + 打字机光标，终端 / 弹幕美学。

- 发光靠**同色三层 `text-shadow`**（8 / 18 / 36px）：近层亮实、远层扩散。别只叠一层大模糊，
  那是「文字发光晕开」而不是「霓虹管」。
- 故障闪烁 `.neon-flicker` 是 7s 周期里 96%-98% 处抖一下，像老霓虹管接触不良；
  多条同屏必须用 `--flicker-delay`（内联 style，单位秒）**错峰**，齐抖瞬间很廉价。
- 光标 `.neon-cursor` 用 `currentColor`，跟在哪种颜色后面就发哪种颜色的光，加 `.typing` 加速闪烁。
- 闪烁与光标在 `prefers-reduced-motion` 下整组关闭（频闪对光敏用户不友好），颜色与发光保留。

### 颜文字 LED 点阵（`.led-face-*` + `MoodFace.tsx` / `mood-faces.ts`）

把一整条颜文字渲染成 LED 灯珠网格，适合做「心情 / 状态」显示。

- 数据是 `'1'`/`'0'` 的 9 行字符串：零件库 36 个符号（括号 / 眼 / 嘴 / 腮红 / 汗滴 …）
  用 `composeFace()` 横拼成整条。**不依赖系统字体**，生僻符号直接画出形状，不会变豆腐块。
- 各条颜文字宽度不同，灯珠尺寸由组件读容器宽度内联算出（封顶 6px / 保底 2px），
  保证整条完整显示；`ResizeObserver` 跟随容器变化。
- 灭珠是固定极淡白 `rgba(255,255,255,0.05)`（**不用 `color-mix`**，老 WebView 也稳）；
  亮珠与光晕走 `--led-color`，换色只改一个变量。
- 「坏灯珠」用**确定性哈希**（`(r*31+c*17) & 0xff`，seed%5 挑中）错开延迟与时长 ——
  不用 `Math.random`：SSR 输出与客户端水合必须逐像素一致，否则 hydration mismatch。

### 影院海报墙（`.cinema-*` + `CinemaWall.tsx`）

多列海报斜着排列、相邻列反方向来回滚动，悬停看片名。

- **斜向滚动的秘密是「容器转、内容走直线」**：整体容器 `rotate(-10deg) scale(1.1)`
  （scale 出血防旋转露角，由外层 `overflow:hidden` 裁掉），列内只是普通 `translateY` 动画。
- 无缝循环：每列内容**复制两份**首尾相接，`translateY 0 ↔ -50%`，循环点自然对齐。
  与第 14 节跑马灯是同一个手法（横竖两个方向）。
- **`.cinema-tilted` 与 `.cinema-cols` 全墙只能有一个**：前者是 `absolute; inset:0`，
  一列建一个会叠成 N 层，只剩最上面那层可见、且它那列被 `flex:1` 撑成满宽 ——
  屏幕上就只剩「一张巨图」。列建在同一个 `.cinema-cols` 里。
- 每列的「一份」内容必须**高过舞台**，否则滚到循环点前会先露出一截空白。
  卡片是 3:4、列宽 ≈ 舞台宽/列数，所以每列至少要
  `3 × 列数 × 舞台高 ÷ (4 × 舞台宽)` 张；`CinemaWall.tsx` 用 `minPerColumn`（默认 4）
  在列内循环补齐，素材少也不塌。
- **奇偶列方向相反 + 每列时长不同**（55/62/50/68/58/64/52s）—— 一来一回且节奏不齐，
  才有「有机感」；全部同向同速会像传送带。
- 悬停某列 `animation-play-state: paused` **整列停滚**（用户要看片名）；
  悬停某张卡触发**聚光灯**：它上抬放大发光，其余卡 `brightness(0.45) saturate(0.75)`
  全部后退 —— 用 `.cinema-stage:has(.cinema-card:hover)` 一条选择器实现，零 JS。
  `:has()` 不支持的老浏览器自动退化为只有单卡发光，布局不坏。
- 卡片默认态要显式写 `filter: brightness(1) saturate(1)`，hover 的亮度变化才有过渡起点。
- 图片加载失败落到「渐变 + 扫描线 + 大字标题」的兜底海报，保住海报感而非空白。
- `prefers-reduced-motion`：列停滚、卡片位移缩放全去，**聚光灯亮度变化保留**（信息层级）。

### LED 霓虹跑马灯（`.neon-marquee-*` + `NeonMarquee.tsx`）

广告牌文字带：暗粉灯箱底 + 灯珠纹理 + 粗等宽字多层光晕 + 灯管高光缝。

- 观感是四层拼出来的：灯箱渐变底 / `radial-gradient` 灯珠瓦片（`mix-blend-mode: screen`）/
  文字 5 层 `text-shadow`（近亮白 2-6px → 远粉扩散 14-48px）/ 上下 1px 高光缝。
  **别只给文字加发光**，没有灯珠纹理和高光缝就只是「发光字」不是「广告牌」。
- 滚动同样是两份内容 + `translateX 0↔-50%`；文字 `phrase` 会被拼成 4 份长串，
  phrase 太短撑不满一屏就多写几段。
- **多条同屏必须闪烁错峰**：`flickerDelay` 给其中一条负值（-2 ~ -3s），
  否则两条同步闪会形成视觉同频干扰。
- 两个可叠加变体：`soft`（薄 56px、光晕收敛、`animation:none` 明确不闪，氛围场景用）、
  `lime`（绿色调：底 `#0a1608`、灯珠/描边/光晕全换 lime、文字 `#eaffd0`）。
- `prefers-reduced-motion`：滚动与闪烁全停（文字静止可见），颜色不变。

## 三条铁律（违反必炸）

1. **`filter` 与 `backdrop-filter` 只能同元素共存，绝不能祖孙共存。**
   祖先只要有 `filter`（哪怕停在 `blur(0)`），子级 `backdrop-filter` 的背景采样立刻失效。
   - 所有 `.enter-*` 模糊入场类只能挂**玻璃块本体**或**纯非玻璃元素**，
     不能挂到玻璃块的容器（网格 `<section>`、wrapper `<div>`）上。
   - 倾斜层的投影必须用 `box-shadow`，**不能用 `drop-shadow`**（那是 filter）。
     唯一例外是 `.card-pop` —— 它在 `.glass-card` 之外，可以安全使用。

2. **`animation: ... forwards` 会钉死元素的 `transform`**，写在同元素 `:hover` 上的
   `transform` 不生效（层叠优先级：动画 > 普通 `:hover`）。
   这就是三层结构的成因：位移挂 `.card-shell`、旋转挂 `.card-tilt`、玻璃与入场挂
   `.glass-card`。**别为了少一层 div 去合并。**

3. **`backdrop-filter` 永不进 `transition` / `animation` 列表。**
   带它的元素 `transition` 必须显式列属性、不能写 `all`。
   否则手指滑动误触发的 `:hover` 会让 GPU 每帧重采样背景 → 掉帧、花屏。

## 验收检查清单

视觉：
- [ ] 玻璃面板背后能看见背景的**形状与颜色变化**（不只是均匀半透明）→ 否则第 2 步漏了
- [ ] 卡片入场是「从雾里化开」而不是单纯淡入 → 否则 `filter` 被挂到了祖先（铁律 1）
- [ ] 桌面 hover 单卡：上浮 + 放大 + 邻卡轻微缩小 + 一道斜光扫过
- [ ] 鼠标移动时卡片跟手倾斜、封面图以更慢速度反向错动
- [ ] 滚出视口再滚回，入场动画会重播

平台：
- [ ] 手机上完全没有 hover 效果（不是「有但很怪」）
- [ ] 开启「减少动态效果」后：位移/缩放/流光全停，颜色与发光仍在
- [ ] 低端安卓滚动不闪屏、不花屏 → 检查是否漏了 CSS 第 9 节，或 `will-change` 常驻了
- [ ] 老 WebView（Chrome < 108）上高度不塌 → 用 `.min-h-viewport`，
      **别用 Tailwind 的 `min-h-[100dvh]`**（老内核认不得会整条丢弃 → 高度塌成 0）

## 浏览器支持与降级

| 特性 | 要求 | 不支持时 |
| --- | --- | --- |
| `backdrop-filter` | 普遍支持（含 `-webkit-` 前缀） | 退化为半透明色块，布局不坏 |
| `mask-mode: luminance` | `@supports` 门控 | `.card-pop` 整层 `display: none`，卡片正常 |
| `100dvh` | Chrome 108+ | 走前面那条 `100vh` 打底 |
| `content-visibility` | Chrome 85+ | 忽略，只是少一层跳绘优化 |
| `:has()` | Safari 15.4+ / Chrome 105+ | 影院聚光灯退化为「只有单卡发光」，布局不坏（渐进增强） |
